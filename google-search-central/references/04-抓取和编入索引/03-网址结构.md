# 适用于 Google 搜索的网址结构最佳实践

> 来源：https://developers.google.com/search/docs/crawling-indexing/url-structure?hl=zh-cn  
> 最后更新时间 (UTC)：2025-12-31。

为了确保 Google 搜索可以有效地抓取您的网站，请使用符合以下要求的可抓取网址结构。如果您的网址不符合以下条件，Google 搜索可能会以低效的方式抓取您的网站，包括但不限于抓取速度极高或根本不抓取。

<td><h3>遵循 <a href="https://datatracker.ietf.org/doc/std66/">IETF STD 66</a></h3>
</td>
<td>
<p>Google 搜索支持 <a href="https://datatracker.ietf.org/doc/std66/">IETF STD 66</a> 中定义的网址。所有被这项标准定义为<a href="https://www.rfc-editor.org/rfc/rfc3986#section-2.2">预留</a>的字符都必须采用<a href="https://developer.mozilla.org/docs/Glossary/Percent-encoding">百分比编码</a>。</p>

</p>
<div></div><pre>https://example.com/#/potatoes</pre>

如果您要使用 JavaScript 更改内容，请改为<a href="https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics?hl=zh-cn#use-history-api">使用 History API</a>。
</p>

<td>

## 让网址结构易于理解

为了帮助 Google 搜索（以及用户）更好地了解您的网站，我们建议您创建简单的网址结构，并尽可能遵循以下最佳实践。

> **注意**：建议您组织一下内容，使网址结构合乎逻辑并特别易于人类理解。
> 如需了解如何整体构建网站，请参阅 [SEO 入门指南中的此部分](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=zh-cn#group-topically)。

如果网络服务器对网址中的大小写文本的处理方式相同，请将所有文本转换为同一大小写形式，以便 Google 能够更轻松地确定网址引用的是同一网页。

</p>

</p>
<div></div><pre>https://example.com/de/</pre>

## 避免与网址相关的常见问题

过于复杂的网址，特别是那些包含多个参数的网址，可能会给抓取工具带来麻烦，因为它们可能会产生大量不必要的网址，全都指向您网站上相同或相似的内容。Googlebot 可能会因此而消耗大量不必要的带宽，Google 搜索也可能无法将网站上的所有内容完整编入索引。

导致网址过多可能有多种原因，其中包括：

<table>
<thead>
</thead><colgroup><col/></colgroup>
<tbody><tr><th colspan="2">常见问题</th></tr>
</tbody><tbody>
<tr>
<td><h3>累加过滤一组项目</h3>
</td>
<td>
<p>很多网站都会针对同一组项目或搜索结果提供不同的视图，通常让用户能够使用指定的条件（例如：显示海景酒店）过滤出该组。当过滤条件可按累加模式组合时（例如：海景酒店，且配有健身中心），网站中网址（数据视图）的数量就会急剧增加。由于 Googlebot 只需查看少量列表就能访问各个酒店的网页，所以没必要创建大量只有细微差异的酒店列表。例如：
</p>
<ul>
<li>“特价”酒店：
<div></div><pre>https://example.com/hotel-search-results.jsp?Ne=292&amp;N=461</pre></li>
<li>“特价”海景酒店：
<div></div><pre>https://example.com/hotel-search-results.jsp?Ne=292&amp;N=461+4294967240</pre></li>
<li>带健身中心的“特价”海景酒店：
<div></div><pre>https://example.com/hotel-search-results.jsp?Ne=292&amp;N=461+4294967240+4294967270</pre>
</li>
</ul>
</td>
</tr>
<tr>
<td><h3>不相关的参数</h3>
</td>
<td>
<p>网址中存在不相关的参数可能会导致大量网址，例如：</p>
<ul>
<li>推荐参数：
<div></div><pre>https://example.com/search/noheaders?click=6EE2BF1AF6A3D705D5561B7C3564D9C2&amp;clickPage=OPD+Product+Page&amp;cat=79</pre>
<div></div><pre>https://example.com/discuss/showthread.php?referrerid=249406&amp;threadid=535913</pre>
<div></div><pre>https://example.com/products/products.asp?N=200063&amp;Ne=500955&amp;ref=foo%2Cbar&amp;Cn=Accessories</pre>
</li>
<li>购物排序参数：
<div></div><pre>https://example.com/results?search_type=search_videos&amp;search_query=tpb&amp;search_sort=relevance&amp;search_category=25</pre>
</li>
<li>会话 ID：<div></div><pre>https://example.com/search/noheaders?sessionid=6EE2BF1AF6A3D705D5561B7C3564D9C2</pre>
<aside>尽可能避免在网址中使用会话 ID，而应考虑使用 Cookie。</aside>
</li>
</ul>
<p>
考虑使用 <a href="https://developers.google.com/search/docs/crawling-indexing/robots/intro?hl=zh-cn">robots.txt 文件</a>阻止 Googlebot 访问这些有问题的网址。</p>
</td>
</tr>
<tr>
<td><h3>日历问题</h3>
</td>
<td>
<p>动态生成的日历可能会生成指向未来及过去日期的链接，而这些日期没有开始或结束日期的限制。例如：</p>
<div></div><pre>https://example.com/calendar.php?d=13&amp;m=8&amp;y=2011</pre>
<p>如果您的网站具有未设置期限的日历，请为指向动态创建的未来日历页的链接添加 <code><a href="https://developers.google.com/search/docs/crawling-indexing/qualify-outbound-links?hl=zh-cn#nofollow">nofollow</a></code> 属性。</p>
</td>
</tr>
<tr>
<td><h3>损坏的相对链接</h3></td>
<td>如果服务器未针对不存在的网页返回正确的 HTTP 状态代码，那么在错误的网页上放置<a href="https://developer.mozilla.org/en-US/docs/Web/API/URL_API/Resolving_relative_references#parent-directory_relative">父级相对链接</a>可能会导致无限空间。例如，<code>https://example.com/category/community/070413/html/FAQ.htm</code> 上的 <code>&lt;a href="../../category/stuff"&gt;...&lt;/a&gt;</code> 等父级相对链接可能会导致 <code>https://example.com/category/community/category/stuff</code> 等虚假网址。
要解决此问题，请在链接中使用根相对网址（而不是父级相对网址）。
</td>
</tr>
</tbody>
</table>

## 解决与抓取相关的网址结构问题

如果您发现 Google 搜索正在抓取这些有问题的网址，我们建议您执行以下操作：

- 考虑使用 [robots.txt 文件](https://developers.google.com/search/docs/crawling-indexing/robots/intro?hl=zh-cn)阻止 Googlebot 访问[有问题的网址](#common-issues)。一般情况下，可以考虑阻止动态网址，例如会生成搜索结果或无限空间（如日历）的网址，以及排序和过滤函数。
- 如果您的网站有分面导航，请了解如何[管理对这些分面导航网址的抓取](https://developers.google.com/search/docs/crawling-indexing/crawling-managing-faceted-navigation?hl=zh-cn#prevent-crawling-of-faceted-navigation-urls)。
