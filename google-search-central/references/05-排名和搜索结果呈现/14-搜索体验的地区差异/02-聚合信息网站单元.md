# Google 搜索中的聚合信息网站单元

> 来源：https://developers.google.com/search/docs/appearance/aggregator-unit?hl=zh-cn  
> 最后更新时间 (UTC)：2026-09-24。

[欧洲经济区 (EEA)](https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:European_Economic_Area_(EEA)) 国家/地区的用户在搜索“附近的酒店”等内容时，可能会发现体验有所变化。这些体验包括聚合信息网站单元和[供应商单元](https://developers.google.com/search/docs/appearance/supplier-unit?hl=zh-cn)。本页面介绍了聚合信息网站单元的运作方式，以及为 EEA 用户提供服务的商家如何申请参与聚合信息网站单元。

![Google 搜索中的聚合信息网站单元](https://developers.google.com/static/search/docs/images/aggregator-unit.png?hl=zh-cn)

## 聚合信息网站单元的运作方式

聚合信息网站单元是一项多提供商功能，专为垂直搜索服务 (VSS) 设计，包括在线旅游平台 (OTA)、购物比较服务、元搜索引擎和目录。借助聚合信息网站单元，用户在进行酒店、航班、长途火车、商品和本地商家相关查询时，就能更轻松地查看来自聚合信息网站的结果。

在这类单元中，符合条件的聚合信息网站会在其单元中展示与用户查询相关的结果。
默认情况下，系统会展开排名最高的提供商的结果。例如，如果用户搜索“巴黎的酒店”，可能会看到一个列表，其中包含排名靠前的酒店及其照片、价格或星级；这些结果均来自符合条件的提供商。用户在该单元内点击某一结果后，会直接前往相应聚合信息网站。

用户可以从备选聚合信息网站列表中选择其他提供商（如有），此操作会展开一个填充了新聚合信息网站结果的单元。一次只会展示一个聚合信息网站单元。

> **注意**：**注意**：为了让直接提供商获得曝光度，Google 搜索会在聚合信息网站单元旁边展示另一个单元。[详细了解供应商单元](https://developers.google.com/search/docs/appearance/supplier-unit?hl=zh-cn)。

## 功能可用性

[EEA](https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:European_Economic_Area_(EEA)) 用户进行酒店、航班、长途火车或巴士、商品和本地商家相关查询时，系统会展示聚合信息网站单元。

## 资格条件

获批成为垂直搜索服务 (VSS) 提供商的商家，只要提供必要的数据，且符合既定的参与质量标准，就可以显示在聚合信息网站单元中：

- **申请参与**：如果您的商家为 EEA 境内用户提供服务，并且您有意参与聚合信息网站单元，可以先填写适用表单：
  - 对于地面交通、航班、酒店和本地商家查询，请填写 [Google 搜索聚合信息网站功能表单](https://support.google.com/websearch/contact/search_aggregator_features?hl=zh-cn)。
  - 对于商品查询，请通过[购物比较服务联系表单](https://support.google.com/css-center/gethelp?hl=zh-cn)与我们联系。
- **拥有相关内容**：由于聚合信息网站单元仅在响应某些查询（例如，酒店、航班、地面交通和本地商家相关查询）时才会显示，因此商家必须拥有与相应查询相关的内容，才可以显示在聚合信息网站单元中。
- **提供数据**：如果符合条件的聚合信息网站希望参与聚合信息网站单元，必须通过直接数据 Feed 集成或实时 API 提供数据，以填充航班或长途火车和巴士等查询的单元。如需详细了解聚合信息网站单元所需数据，请参阅适用指南：
  - 对于酒店查询，请参阅[住宿地图注点 Feed](https://developers.google.com/actions-center/verticals/lodging/overview?hl=zh-cn) 文档。
  - 对于地面交通查询，请参阅[交通功能 API](https://developers.google.com/travel/transport?hl=zh-cn) 文档。
  - 对于航班查询，请参阅[合作伙伴标准 Live API](https://developers.google.com/travel/flights/otas_guides/live-API-specification?hl=zh-cn) 文档。
  - 对于商品查询，请了解[如何开始在 Google 各平台上展示商品页面](https://support.google.com/css-center/answer/14157117?hl=zh-cn)。
  - 对于本地商家查询，请参阅[本地地图注点 Feed](https://developers.google.com/actions-center/verticals/local_vss/integration-steps/overview?hl=zh-cn) 文档。
- **遵守 Google 搜索内容政策**：聚合信息网站单元中的所有内容都必须遵守 Google 搜索的[内容政策](https://support.google.com/websearch/answer/10622781?hl=zh-cn)。

## 聚合信息网站单元最佳实践

此单元旨在方便用户找到对其查询有所帮助的实用聚合信息网站。对于航班和交通查询，该单元由实时 API 填充。对于住宿和本地商家查询，该单元由直接数据 Feed 集成填充。与我们的所有搜索功能一样，我们会基于对用户查询最有帮助的内容，在单元中展示相关信息。如需详细了解我们对搜索质量的看法，可以前往[我们的博客](https://developers.google.com/search/blog/2023/11/search-quality-rater-guidelines-update?hl=zh-cn)，查看搜索质量评分者指南。

为了帮助您为用户提供尽可能优质的体验，建议您遵循以下关于此功能的最佳实践：

- **提供丰富的实体详细信息**：尽可能提供更全面的属性，这有助于用户更好地评估选项。根据您的商家类型，考虑提供以下内容：
  - 实体的图片
  - 详细的说明和规格
  - 经验证的用户评分和评价数量
  - 具体类别（例如，“精品酒店”或“生态度假村”，而不是仅使用宽泛的“酒店”）
  - 主要设施、特色和营业时间
- **使用准确的标题**：标题应真实且富有描述性，并采用词首字母大写格式，这样更便于用户阅读。建议您避免在实体名称中使用全部大写格式、过多标点符号、表情符号或促销文字（例如“BEST DEALS”或“免运费”）。
- **提供高画质图像**：清晰的原创照片能够让用户更好地了解相应地点或服务。为实现最佳展示效果，请使用背景干净、无水印或促销信息叠加层标记的图片。尽可能提供高分辨率照片。
- **及时更新价格和库存状况**：提供精准的数据有助于避免让用户失望，给他们带来不好的体验。确保 Feed 中的价格和库存状况尽可能与着陆页上的信息保持一致，并定期刷新 Feed 以移除已过期或缺货的商品详情。
- **监控整体效果**：使用 [Search Console](https://search.google.com/search-console/about?hl=zh-cn) 及时了解 Google 搜索中的情况。
