# UGC 新鲜数据计划

> 来源：https://developers.google.com/search/docs/appearance/ugc-fresh-data-program?hl=zh-cn  
> 最后更新时间 (UTC)：2026-10-13。

UGC 新鲜数据计划是一项旨在协助各大平台在 Google 搜索的各项功能中，展示新鲜、优质且真实的用户生成内容 (UGC) 的计划。通过此计划，获批平台可以使用专用数据注入流水线向 Google 发送内容和互动信号。这种主动式方案有助于确保新鲜内容在 Google 搜索中得到快速处理和更新，让用户能够轻松发现来自您平台的实用第一手观点。

> **注意**：UGC 新鲜数据计划是专为热门 UGC 内容设计的专用流水线。它独立于 Google Indexing API 和针对一般 Web 内容的传统自然抓取。

> **注意**：此计划不保证内容一定会显示在 Google 搜索中。

## 资格条件

由于技术要求和集成性质，只有符合特定内容质量和数量准则的平台才能参与。平台必须满足以下条件：

- **内容重点**：平台必须主要托管 UGC 内容、社交帖子或论坛讨论。UGC 内容应托管在具有稳定网址的专用页面上，而不是个人资料或信息流页面上。

  > **注意**：UGC 是指由在线平台或聚合信息网站托管和分发，但完全由独立用户而非平台本身创建的任何数字资料。
- **内容量和受众群体**：UGC 内容量大，用户群庞大。
- **内容可访问性**：内容必须位于 Googlebot 和用户可访问的公开网页上；设限内容（需要登录或付费才能查看）不符合条件。此外，所有 UGC 都必须明确署名具有公开个人资料的创作者。
- **技术准备**：平台所有者必须有能力实现安全的 OAuth 2.0 API 身份验证，并构建经过严格验证的 JSON-LD 载荷。此外，该平台必须已在其网址中采用（或准备好实现）有效的网页级 schema.org 结构化数据标记。例如，`SocialMediaPosting` 或 `DiscussionForumPosting` 及其 `interactionStatistic` 子字段。
- **内容健康和审核**：平台不得发布非法内容，并且必须积极审核内容，包括提供用户举报机制。
- **内容时效性**：提交的内容必须尽可能新鲜，最好在几分钟内发送。
  此外，您必须能够定期提交互动计数器的更新（在创建后的 72 小时内）。
  在您获准加入该计划后，我们会与您分享开发者文档，其中包含更多详细信息。
